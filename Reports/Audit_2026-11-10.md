# AIAgentCoreRules Audit — 2026-11-10

One-off audit of the core rules repo (and where it overlaps, TripleMatchAiMetaData): empty spots,
duplicates, and what is working vs not after ~7 weeks of retro-driven changes.

**Evidence base:** 191 session folders (2026-09-25 → 11-10), 124 retros (327 proposals, 111
correction rows), 3 meta reviews (38 tickets), 155 top-level + 124 subagent transcripts
(W42–W46 only; older transcripts are deleted), and both repos' git history. Detail and scripts
are in [`Audit_2026-11-10/`](Audit_2026-11-10/):

| Appendix | Covers |
|---|---|
| `audit_static.md` | broken refs, orphans, duplication, Documentation/ drift, bloat (file:line) |
| `audit_retros.md` | every meta-review ticket's status, retro themes, recurrence after fix |
| `audit_router.md` + `audit_router.py` | lane mix, file-load counts, router-check compliance, cost, metric health |
| `audit_tools.md` + `audit_tools.py` | tool/skill invocation counts, tool-vs-manual ratios, typecheck and /audit discipline |

The two scripts are re-runnable (`python3 <script>`); they read the session folders and transcripts in place.

---

## 1. Headline

1. **Fixes that change structure stick; fixes that add prose don't.** Single-fact knowledge
   entries, hard project rules (§VII prize push, [SECRET], §VIII IL2CPP), tool bug fixes, the
   retro template's Documentation/ field and the shell-read hook all held. Every behaviour
   problem answered with *more rule text* recurred after the fix: load-the-Systems-entry-first
   (~9 recurrences after 10-05), [BEHAV] unverified claims (~10 after 10-20), scope misread /
   not reusing existing code (largest category, flat), design docs asserting unconfirmed
   decisions, background-job isolation, Confluence placeholder publish, worktree friction.
2. **The feedback loop is broken at the top.** The weekly meta review — the only check for
   "did it come back after we fixed it" — has not run since 2026-10-16 (~130 sessions).
   34% of sessions never run `/end-session`, and those include the most expensive ones
   (70M, 43M, 36M, 32M tokens).
3. **The rules are growing faster than they are being followed.** Rule text roughly tripled
   since 10-05 (SmallTask.md 432 → 1,396 words; StopAndVerify 360 → 1,144). Always-loaded text
   is ~6.1k words (~8k tokens) re-sent every call. Rule loads themselves are cheap (~6% of
   tokens); the cost is attention, not tokens.
4. **Tools: adopted where they are the only path, ignored where grep is easier.**
   `typecheck.py` (94% vs manual), `feature_state.py` (97–100% since 11-02),
   `session_lifecycle.py`, `doc_review.py` are healthy. `codeindex`/`usages` win only 19% of
   type lookups (477 type-greps over C#); shape-only whole-file `.cs` reads got *worse*
   (tool share 47% → 20%). 58 manual greps happened within 20 tool calls of loading a rule
   that names the tool.

### 3.3 Feedback and measurement gaps

- **No meta review since 10-16.** Every "re-check next review" item is unchecked;
  `open-meta-review-tickets.md` memory last updated 10-19. Implemented-but-unverified:
  MR-16-03 (<10% retro tokens), MR-16-09 (verify-after-publish — then 11-04 placeholder
  publish), MR-16-06, MR-02-04 (closed by redefinition), MR-02-05/06, MR-16-04/05 (grep-only
  done-whens, behaviour returned).
- **Router-check results exist only as free text in retros** — 25+ spellings of "loaded?"
  ("✓", "yes", "not needed", "skipped, correctly"…), ~20% filler rows.
- **/audit and /discover are invisible to the router trace**; they show up only in retros.
- **`RUNNABLE_TOOLS` in `Tools/session-lifecycle/session_lifecycle.py:68` omits `unitysource.py`.**
- **Context warning is relative** (90% of median peak) — fires in 46% of sessions since 11-02

- **/inaccuracy has 0 engineer uses**; the inaccuracy metric is 100% agent self-report
  (MR-20261009-12). 67 retros report "no corrections".
- 15% of sessions have an empty router trace; 19 sessions never set a lane (two of them real:
  840ac78c 7.5M, 2e2966d6 43.1M); 10 still show "Ended = in progress".

## 6. Caveats

- Transcripts only cover W42–W46; tool-vs-manual ratios start there. metrics.md goes back to W39.
- "Type lookup" = recursive grep for a PascalCase name over C# (sample of 10 checked);
  "shape-only read" = whole-file read of a file not edited that session — approximate.
- Retro-reported miss share rose in November partly because checklists got longer
  (~5.5 → ~7 rows per retro), not only because behaviour got worse.
- Recurrence counts come from retros, which are self-reported and missing for 34% of sessions —
  true recurrence is likely higher.
